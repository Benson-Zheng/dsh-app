# 全新电脑安装 dsh app

面向一台**新的 Windows 10/11** 电脑。dsh app 只是外壳，真正的 `dsh` 要单独安装，之后可以单独升级。

按顺序做下面 4 步即可。

## 1. 安装 Node.js

1. 打开 [https://nodejs.org/](https://nodejs.org/)
2. 下载并安装 **LTS**（建议 22.x，至少 18+）
3. 安装时勾选把 Node 加入 PATH
4. **新开**一个 PowerShell 或「命令提示符」，检查：

```powershell
node --version
npm --version
```

能看到版本号即可。旧窗口可能还没有刷新 PATH，请关掉重开。

## 2. 单独安装 dsh（不是装进 exe 里）

```powershell
npm install -g @deepseek-ai/dsh
```

检查：

```powershell
dsh --help
```

以后升级 **只更新 CLI**，不用重装桌面应用：

```powershell
npm update -g @deepseek-ai/dsh
```

`dsh-app-setup.exe` / `dsh-app.exe` 不会冻结一份 `dsh`。每次打开 dsh app 都会用你 PATH 上那份。

## 3. 安装或运行外壳

从本仓库构建产物（`dist/`）拿走其中一个：

| 文件 | 用途 |
|---|---|
| **`dsh-app-setup.exe`** | 安装程序：开始菜单 + 桌面快捷方式「dsh app」 |
| **`dsh-app.exe`** | 便携版：双击即可，不写开始菜单 |

- 推荐全新电脑用 **`dsh-app-setup.exe`**，一路下一步即可。安装向导会**检测本机是否已有 dsh**；没有时点「立即安装 dsh」，由安装程序替你执行 `npm install -g @deepseek-ai/dsh`。不会把 `dsh` 打进安装包。第一次打开 dsh app 若仍缺 CLI，窗口里也有「一键安装 dsh」。
- 没有安装权限时用 **`dsh-app.exe`**。
- Windows SmartScreen 可能提示未知发布者：选「更多信息」→「仍要运行」。

不要只把 `dsh` 装进应用目录里当唯一后端。外壳和 CLI 是两套东西。

## 4. 第一次打开 dsh app

1. 开始菜单或桌面点 **dsh app**（或双击 `dsh-app.exe`）
2. 窗口会启动 `dsh web`，然后显示 DeepSeek Harness 界面。顶部栏可切换 **会话** / **插件广场**
3. 若提示找不到 `dsh`：回到第 2 步，装完后**完全退出**托盘再打开（托盘右键 **Quit**，不要只关窗口）
4. 关窗口会藏到托盘，`dsh web` 继续跑；真正退出用托盘 **Quit**

模型、密钥、会话在用户目录 `C:\Users\<你>\.dsh\`（`settings.yaml`、`.credentials.yaml`）。新电脑需要自己再配 API Key，不要拷贝别人的密钥。

## 以后怎么更新

```powershell
npm update -g @deepseek-ai/dsh
```

关掉 dsh app（托盘 Quit）再打开。**不用**重装 `dsh-app-setup.exe`。

只有外壳本身要换版本时，才再跑一次 `dsh-app-setup.exe` 或换新的 `dsh-app.exe`。
